# Wellness Note ♡

毎日の小さな習慣を記録して、自分の生活をもっと大切にするためのウェルネス記録アプリです。

**🌷 公開サイト：** [Wellness Note を開く](https://k-tsuji11.github.io/react-todo-app/)　　

---

## ✿ Concept

「毎日を頑張る自分の変化を、楽しく記録したい」

健康管理や習慣づくりは、継続することが大切です。しかし、一般的な管理アプリは機能が多く、入力が面倒に感じることもあります。

そこで、毎日の記録を簡単に入力でき、かわいいデザインで楽しく続けられるアプリを目指して開発しました。

ピンクやラベンダーを基調とした、やわらかく親しみやすいデザインが特徴です。

## ✿ Main Features

### 1. 毎日の健康記録
- 水分補給：飲んだコップの数を記録
- 睡眠：睡眠時間を記録
- 気分：その日の気分を選択
- 運動：運動した時間を記録
- 食事メモ：食べたものや感想を自由に入力

### 2. 習慣管理
- 自分だけの習慣を追加
- 習慣のカテゴリーを設定
- チェックボックスで達成状況を管理
- 不要になった習慣を削除
- 今日の習慣達成率を表示

### 3. 週間グラフ
- 過去7日間の水分補給量をグラフで表示
- 日ごとの記録を視覚的に比較

### 4. データ保存
- LocalStorageを使用
- ページを再読み込みしても記録を保持

## ✿ Design & UI/UX

- ピンク・ラベンダーを中心とした配色
- 丸みのあるカードデザイン
- 見やすく整理された入力フォーム
- スマートフォンでも使いやすいレイアウト
- シンプルな操作で記録できる設計
